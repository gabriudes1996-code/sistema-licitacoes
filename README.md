# LicitaPro — Sistema Web Local

Primeira versão de um sistema local para gestão e formação de preços em licitações.

## Requisitos
- Node.js 18.18+ (recomendado Node 20+)
- npm

## Como executar

No Terminal, entre na pasta do projeto e execute:

```bash
npm install
npm run dev
```

Depois abra:

http://localhost:3000

## O que já funciona
- Dashboard
- Menu lateral
- Calculadora de custo
- Cálculo de impostos
- Cálculo de preço sugerido pela margem
- Simulador de lance
- Cálculo de lucro e margem em tempo real
- Layout responsivo
